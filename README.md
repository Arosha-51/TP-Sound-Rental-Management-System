# Automated Equipment Rental & Rental Contract Management System

This project proposes the development of a web-based Automated Equipment Rental & Rental Contract Management System tailored for Small and Medium Enterprises (SMEs) in the event production and music industry. The proposed solution digitizes inventory tracking, automates rental contract management, prevents item overbooking, and calculates late return penalties automatically.

## 🎯 Target Client
**T.P. Sound & Musical Gear Rentals**
- **Proprietor:** Mr. Tony Prabath (Owner & Music Instructor)
- **Location:** Kuruwita, Sri Lanka
- **Business Type:** Sole Proprietorship (Single Owner SME)

## ✨ Key Features
- **Automated Inventory Tracking:** Real-time dynamic inventory catalog to prevent booking overlaps.
- **Digital Contract & PDF Generation:** Automatically generates standardized PDF rental contracts outlining clear damage policies and terms.
- **Automated Late Return Penalty Calculation:** Integrates an automated fee calculator based on contract duration and delay days.
- **Centralized Booking Management Dashboard:** Intuitive dashboard for the proprietor to manage active rentals, returns, and client records efficiently.

- **Database:** MongoDB (Mongoose ODM)
